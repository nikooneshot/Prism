# Aether

A lightweight desktop utility for Linux that bundles everyday dev tools into a clean, dark glass interface. Instead of opening random web converters or digging through terminal flags, everything runs locally in a single window.

Built with Tauri 2.0 and Rust so it doesn't eat 600MB of RAM like an Electron app.

### What's inside

- **Port Sentinel:** See what’s listening on your local ports and kill stubborn stuck processes without typing `lsof` / `kill -9`.
- **JSON Lens:** Format, minify, and validate JSON payloads with syntax highlighting.
- **Crypto & Hash:** Generate MD5, SHA-256, and Base64 hashes instantly, plus decode JWTs offline.
- **Epoch Studio:** Live Unix timestamp tracker and date converter.
- **System Stats:** Quick glance at CPU, memory, and uptime.
